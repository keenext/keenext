## 0.1.0 – Unreleased
### Added
- Open and edit KeePass databases (KDBX 3.1 and 4.x) stored in Nextcloud. The master password and the contents never reach the server.
- Open `.kdbx` files from the Files app and create databases from its "New" menu.
- Changes made elsewhere, for example with KeePassXC, are merged instead of overwritten.
- Import from CSV, Bitwarden JSON, KeePass XML and other databases; export as KeePass XML or CSV.
- Health check with an optional Have I Been Pwned lookup, one-time codes (TOTP) and a password generator.
- English and German translations.

This is an alpha release. What is missing is listed in [docs/features.md](docs/features.md).
